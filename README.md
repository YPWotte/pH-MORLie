# pH-MORLie
Repository for model order reduction via Lie groups and the application to port-Hamiltonian systems, implemented in Julia. Coming soon.

For more information take a look at our original article on [MORLie](https://www.sciencedirect.com/science/article/pii/S1007570426003321) and corresponding [GitHub-repo](https://github.com/YPWotte/MORLie), or my thesis chapter on [pH-MORLie](https://research.utwente.nl/en/publications/geometric-methods-for-dynamics-optimization-and-model-order-reduc/) (Chapter 3).
